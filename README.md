## Qué hay

El PDF no trae los 256 odú: faltan varias combinaciones (sobre todo tramos de Iwori, Odi e Irosun con las piernas posteriores). No se inventaron.

## Cómo leer un omo odú

En este linaje (Ode-Remo) el *opele* se lee **de derecha a izquierda**:

- **Derecha:** lo que ya se está manifestando
- **Izquierda:** lo latente o en potencia
- **Ire:** orientación de buena fortuna
- **Ibi:** orientación de obstáculo

Las frases clave de las 16 piernas se combinan; el libro advierte que **no sustituyen los versos** (*ese Ifá*).

## Límites

- Notas de estudio, **no** una edición del libro ni un manual de iniciación.
- Ifá se describe como el autor lo presenta: sistema metafísico / religioso, no ciencia verificada.
- No hay procedimientos rituales paso a paso (consulta, *ebo*, sacrificio).
- Afirmaciones de salud se copian como *claims* del libro, no como consejo médico.
- La adivinación con este oráculo, según el propio texto, queda para quien tiene *tefá*.

## Yoruba que no se traduce

Odú, *oriki*, *ase* / *aşé*, *ori*, *ire*, *ibi*, *ebo*, *awo*, *egbe*, *ikin*, *opele*, *opon*, nombres de òrìṣà y fórmulas de rezo.
