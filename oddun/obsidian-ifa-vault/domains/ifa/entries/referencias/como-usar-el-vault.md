# Cómo usar este vault

1. Empieza por [[domains/ifa/README]] y [[COMPENDIO]].
2. Si tienes un Meji, abre `entries/meji/`.
3. Si tienes un compuesto, abre `entries/omoluo/{padre}-{segundo}`.
4. Completa las secciones vacías con el ita de **tu** casa. No pegues capítulos del PDF.
5. El agente solo rankea keynotes y compara familias. No tira caracol ni prescribe ebó.
