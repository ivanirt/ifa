# Él hizo adivinación para los genitales humanos

Él hizo adivinación para los genitales humanos.

Edi gbagba, [[Iwori]] le le, adafa [[Fun]] onisinkin ti 
ongb'[[Ogun 1]] lo si orima sun gbun.

Él hizo adivinación para el Pene cuando él iba 
hacerle la guerra a la vulva. Al Pene se le dijo que
hiciera sacrificio con el objeto de ganar en su 
guerra. Se le dijo que hiciera [[Ebo]] con un gallo y un
cacho de venado. Él hizo el sacrificio. Como el Pene
era muy flácido para mantenerse erecto, [[Eshu]] le dio 
una prenda para que lo usara con el cacho de venado 
con el cual hizo el sacrificio.
Después de usar la prenda, el ya podía mantenerse 
erecto antes de atacar la vulva. La erección le dio 
a el un fácil pasaje a través de ella.
Es así que el Pene de ahora en adelante tiene éxito 
en la guerra con la vulva. No es necesario mencionar
que el Pene no puede penetrarla s que primero este 
en erección.
