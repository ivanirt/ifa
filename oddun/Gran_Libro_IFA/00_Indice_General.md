# 📖 El Gran Libro de Ifá (Volumen 1)

Base de conocimiento estructurada para Obsidian a partir del documento **`el gran libro de ifa 1.pdf`** (255 páginas). Este volumen constituye el compendio operativo y ceremonial esencial para el sacerdocio de Ifá: invocaciones primarias, adivinación con coco (*Òṣé Bìlè*), botánica sagrada (*Ewé Òsanyìn*), rezos y firmas de tablero (*Atenas*) e iniciaciones litúrgicas.
